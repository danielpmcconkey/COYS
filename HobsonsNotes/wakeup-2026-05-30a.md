Built and deployed the full Marcus v2 stack in a single session:

**U1 — Schema migration** (`scripts/migrations/001-v2-schema.sql`):
New tables: `marcus.conversation`, `marcus.channel_stats`, `marcus.queue`.
New columns: `channel.blacklisted`, `channel.blacklist_reason`,
`video.discovered`, `video.completion_pct`. Dan applied the migration
manually (Hobson can't sudo to marcus).

**U9 — Watch-sync extension:** `watch_sync.py` now calls
`db.set_video_watched(vid, completion_pct=pct)` instead of
`db.update_video_status(vid, "watched")`. Stores completion percentage
for taste learning. Service restarted.

**U2 — Marcus listener** (`agents/marcus/listen`): Forked from
`bin/listen`. Adds conversation memory — logs every message/response to
`marcus.conversation`, loads the 2PM–2AM ET window as context prefix on
each `claude -p` invocation. Dedicated systemd service
`coys-marcus-interactive.service` (runs as marcus user). Old
`coys@marcus.service` disabled.

**U3 — Catalog refresh** (`scripts/refresh_catalog.py`): Standalone
script for on-demand catalog maintenance. RSS sync, metadata enrichment,
video expiration. Replaces the catalog portion of `run_daily.py`.

**U4 — Taste aggregation** (`scripts/taste.py`): Computes per-channel
quality scores from watch-sync completion data. Formula:
`score = (avg_completion * 0.7) + (watch_ratio * 0.3)`.

**U5 — Curation + queue** (`scripts/curate.py`, `scripts/queue_push.py`):
`curate.py` queries candidates with taste signals for Claude to curate
from. `queue_push.py` pushes the playlist URL to SmartTube via ADB.

**U6 — Blacklist:** Functions and CLI verbs added to `db.py`
(`--blacklist-channel`, `--list-blacklist`). All existing curation queries
updated with `WHERE blacklisted = FALSE`.

**U7 — Discovery** (`scripts/discover.py`): YouTube Search API discovery.
Finds new channels based on top-performing channel categories.

**U8 — CLAUDE.md rewrite:** Complete rewrite for DJ mode. On-demand
queues, taste profile, conversation memory, blacklist commands, discovery.
No more rigid tier-based daily build procedure.
